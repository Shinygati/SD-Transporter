About this companion

An independent educational homebrew project by Shinygati, developed with assistance from OpenAI Codex and Anthropic Claude.

This project is not affiliated with or endorsed by Nintendo, Creatures, Game Freak or The Pokémon Company. Product and game names identify compatibility. Game graphics displayed from a walker are supplied by the user's file; retail ROMs, saves and firmware are not bundled.

Source and licence

Read the GPL licence

The original companion code is GPL-3.0-or-later. Corresponding source, build instructions, complete licence notices and credits are supplied with SD Transporter.

SD Transporter source repository

TWiLight Menu++ and nds-bootstrap provide the upstream console projects. The standalone companion shares SD Transporter's walker-format and gameplay implementation. Pokéwalker research by Dmitry Grinberg and the CC0 lumirth/pw reconstruction informed the format and mechanics. Research references and upstream licence details are recorded in the source distribution.

English Pokémon names follow the National Pokédex mapping documented by PKHeX. English item names retain the HGSS spellings documented in the pret/pokeheartgold item-name bank. These are factual compatibility mappings.

The phone's operating system supplies standard UI, networking and step-sensor services. The app includes no advertising or analytics SDK.
